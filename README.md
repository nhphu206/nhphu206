## Featured projects

### [Nha Be Radar–Himawari Forecasting Pipeline](https://github.com/nhphu206/nhabe-radar-himawari-portfolio)

End-to-end scientific data and deep-learning project for spatially aligning Nha Be weather-radar
and Himawari-9 observations, then forecasting the next radar-reflectivity volume.

- processed **8,916 radar volumes** into **8,774 audited radar–satellite samples**;
- constructed **822 causally screened forecast pairs** with time-based splits;
- compared persistence, radar-only and multimodal Small U-Net models;
- achieved **5.904 dBZ locked-test RMSE**, 20.30% below persistence;
- packaged reproducible demonstrations with FastAPI, Docker, Compose and GitHub Actions.

- preserve raw data and keep generated products traceable;
- use tests and data contracts instead of relying on file existence;
- separate training, validation and locked-test decisions;
- report limitations and negative or small improvements without exaggeration;
- keep demonstrations reproducible without publishing restricted data or secrets.
